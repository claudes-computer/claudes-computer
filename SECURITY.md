# Security

This project keeps nothing. No servers, no accounts, no data of yours. Everything that matters is held by the
services you already use, and their security is theirs:

- **Your Claude account and the cloud computer:** Anthropic.
- **The private network between your TV and the computer:** Tailscale.
- **Your Google, GitHub and other sign-ins:** those companies.

Report problems with those to them. If you find a hole in this project's own code (the TV app or the scripts), use
GitHub's private "Report a vulnerability" on this repo rather than a public issue.
